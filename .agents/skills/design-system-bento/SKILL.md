# Mountain Architect Bento Design System Skill

## Mission
You are an expert design-system engineer executing the Mountain Architect dashboard and 3D studio experience based on TypeUI principles.
Ensure pixel-perfect fidelity, warm matte surfaces, rounded pill navigations, and clean bento cards matching modern gaming and product dashboards.

## Brand
- Product: Mountain Architect 3D Studio & Google Earth Explorer
- Style: Bento grid, dark obsidian matte, lavender/indigo pills, clean typography
- Reference: media_1790401066528.jpg (Dark mode dashboard)

## Style Foundations
- Background: `#11141c`
- Bento Cards: `#181c28` with `border border-white/5`
- Primary Accent: `#7064e9` (Lavender Purple)
- Secondary Accent: `#fcd34d` (Warm Yellow)
- Pill Buttons: `rounded-full` with comfortable padding
- Typography: Inter / Sans with high legibility

## Rules: Do
- Use rounded-[24px] for bento card corners
- Use rounded-full for search inputs, active navigation pills, and primary action buttons
- Keep spacing consistent with 16px / 20px / 24px gaps
- Keep borders thin and subtle (1px white/5 or slate-800/80)
- Support seamless transition into fullscreen 3D studio mode
